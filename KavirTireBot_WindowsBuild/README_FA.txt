ساخت فایل اجرایی ویندوز ربات کویر تایر

این بسته هنوز فایل EXE نیست؛ فایل EXE باید روی runner ویندوز GitHub Actions ساخته شود.

روش ساخت:
1) وارد github.com شوید و یک مخزن جدید (New repository) بسازید.
2) فایل‌های داخل این پوشه، از جمله پوشه مخفی .github، را در مخزن بارگذاری کنید.
3) از زبانه Actions، گردش کار Build Windows EXE را باز کنید.
4) اگر اجرا نشده، دکمه Run workflow را بزنید و اجرای آن را تأیید کنید.
5) پس از پایان موفق، در همان صفحه بخش Artifacts را باز کنید و KoVirTireBot-Windows-EXE را دانلود کنید.
6) ZIP دانلودشده را Extract کنید؛ فایل KoVirTireBot.exe داخل آن است.

نکته‌ها:
- ساخت EXE به اینترنت در محیط GitHub برای دریافت وابستگی‌ها و Chromium نیاز دارد؛ روی رایانه شما نصب Python یا Playwright لازم نیست.
- فایل اجرایی به‌همراه مرورگر Chromium بسته‌بندی می‌شود و ممکن است حجیم (چندصد مگابایت) باشد.
- این بسته‌بندی هنوز روی ویندوز اجرا و آزمایش نشده است؛ ابتدا با ورود دستی و بدون پرداخت، عملکرد را بررسی کنید.
- ورود، کد پیامکی/CAPTCHA و پرداخت با خود کاربر است.
- مقدار پیش‌فرض 165/60R13 و KB2000 طبق درخواست تنظیم شده؛ وجود همین ترکیب در فهرست رسمی فروش تأیید نشده است. آن را از فهرست واقعی انتخاب یا دستی اصلاح کنید.
